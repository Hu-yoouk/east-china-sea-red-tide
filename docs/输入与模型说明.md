# 输入与模型说明

## 预测对象

使用研究区过去连续 12 个月的环境月均值预测下一月项目区域标签。范围为 120.5°E—123.5°E、29.0°N—32.5°N，195 个 0.25° 规则网格。预测是区域整体的月度二分类，不是网格风险，也不是赤潮面积或具体发生日期。

第一版应使用 Python 3.12，模型不需要 GPU。默认发布模型训练标签截止 2017-12，2018—2019 用于早停，2020—2023 独立测试；没有把测试期加入发布模型的训练集。

## CSV 格式

每月一行，必须覆盖固定研究区；完整示例见 `examples/observations_2019.csv`。

| 字段 | 含义与单位 |
|---|---|
| year、month | 年、月，整数 |
| sst | 海表温度，℃ |
| chlorophyll | 原始可用叶绿素观测的区域均值，mg/m³；允许空值 |
| chlorophyll_coverage | 当月有原始叶绿素观测的网格数 / 195，0—1 |
| wind_speed | 风速，m/s |
| pressure | 气压，Pa；1013 hPa 应换算为 101300 Pa |
| solar_radiation | 太阳辐射，W/m²，沿用原项目转换后的口径 |
| precipitation | 降水，mm/day，沿用原项目转换后的口径 |
| salinity | 实用盐度 |
| nitrate、phosphate、silicate | 营养盐，μmol/L |
| red_tide_label | 仅历史/训练文件需要；预测不使用该字段 |

除叶绿素外不允许缺测。叶绿素空值必须对应覆盖率 0；其他情况覆盖率大于 0。必须至少连续 12 个月，不能重复月份。程序排序后使用最后 12 个月，目标为最后一月的下一月。需要预测其他月份时，应准备截止于对应预测起点的输入。

逐网格新数据需先检查每月 195 个网格完整且键不重复，再按同一网格集合等权平均。叶绿素仅使用实际可用观测计算均值，记录覆盖率，不能把机器学习插补值标记为观测。不同区域、单站或只有一月的数据不能直接代入本入口。

## 特征与学习过程

- 各环境变量及叶绿素覆盖率：最后月、最后三月均值、最后十二月均值、最后月减前两月。
- 目标月份的正弦和余弦：日历信息已知，不需要未来环境数据。
- 共 46 个特征。缺测派生特征用训练期中位数补齐，没有全数据拟合的标准化器。
- LightGBM 使用固定参数和固定随机种子，通过验证集二元交叉熵早停。
- 同月历史基准只用训练期对应月份标签，加一平滑。
- 未进行独立概率校准；0.5 仅用于报告分类指标，不是生态或官方预警阈值。

## 输出

`prediction.json` 提供输入与模型校验值、预测起点、目标月、概率、季节基准、局部贡献和适用条件。`report.md` 提供中文解释，`report.html` 提供可直接打开的离线报告。

局部贡献使用 LightGBM 内置 TreeSHAP 计算，数值单位是对数几率；正值推高当前模型输出，负值拉低，不是独立变量的因果影响。

本流程是历史环境数据上的提前一月回溯预测。实际业务预测需确认全部输入在预测发布时已获得；数据产品发布延迟、上游转换和环境漂移尚未通过业务试运行验证。
