# 评委演示流程

提前按 README 安装 Python 3.12 和固定依赖。演示不必访问互联网网站。

1. 展示 `SKILL.md`：不同 Agent 读取同一规范，调用同一模型。
2. 展示 `examples/observations_2019.csv`：12 个月区域环境汇总，不需要输入标签。
3. 提问：“这份数据覆盖固定研究区，请运行真实模型，预测下一月并解释。”
4. 展示终端执行过程，结果应为 2020-01、约 17.22%，季节基准约 13.33%。
5. 打开生成的 HTML：查看日期、范围、预测、基准、测试指标和模型贡献。
6. 追问：“2021 年有多少个月出现区域赤潮标签？”实际查询应返回 8 / 12。
7. 提交 `invalid_missing_pressure.csv`：应指出缺气压而不生成概率。

建议说明：“我们将数据、研究说明和运行入口封装成可调用技能。针对下一月任务重新训练了 LightGBM 基线，原论文融合实验与新增预测分别记录，执行结果与依据都能追溯。”

Windows 本机安装完成后可双击 `演示.cmd`；它运行历史样例。真正新数据需通过 Agent 或命令行指定新的 CSV。

`web/` 用于展示原项目背景，其规则评分不是新模型。不能宣称已实现明日逐网格预报、接入最新在线观测或业务预警。
