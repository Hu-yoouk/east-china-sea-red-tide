# 材料与来源

原网站附有木兰宽松许可证第 2 版，本交付沿用许可并保留文本。新增程序、说明和测试位于主目录；`web/` 保留原网站，增加用途提示并改为可迁移路径。

## 数据和模型

- `data/monthly.csv`：由用户提供的 `integrated_database.db` 汇总为 240 个月，标签沿用原项目。
- 叶绿素：来自用户提供的 `chlorophyll_grid_data.csv` 原始观测，项目来源说明指向 ESA Ocean Colour CCI。
- 其余环境数据：沿用项目海温、ERA5 气象、盐度、营养盐处理结果，原产品转换和发布时效未全面重核。
- `models/regional_v1/`：由本仓库训练代码及月度 CSV 生成，文本格式权重，无需加载 pickle。
- `web/public/data/`：原网站派生数据，与新模型叶绿素处理和标签统计口径不完全相同。

源文件和派生 CSV 校验见 `data/monthly.provenance.json`。数据来源说明不是完整的数据许可核验，上游再分发条件不由代码许可证覆盖，公开发布前需核实派生数据与材料范围。

大型 NetCDF、SQLite、重复压缩包、录屏工具、PPT 缓存和账户配置未纳入。日常预测不依赖它们。原材料存在账户字段，因此只复制选定代码与报告，不能直接整目录公开原始资料。

原项目文件未修改。`legacy/` 的代码仅用于追溯，不承诺脱离原目录可直接运行。
