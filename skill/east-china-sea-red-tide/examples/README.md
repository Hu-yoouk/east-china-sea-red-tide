# 演示样例

- `observations_2019.csv`：2019 年真实历史环境汇总，不含标签；预测目标为 2020-01。该目标属于独立测试期。
- `observations_2023.csv`：2023 年历史环境汇总；预测目标为 2024-01。没有随包提供该月真实标签，不能报告该月预测准确率。
- `invalid_missing_pressure.csv`：故意删除气压字段，用于检查拒绝不完整输入。
- `result_2020_01/`：实际运行保存的 JSON、中文 Markdown 和 HTML 报告。

这些样例用于证明推理流程，不应改年份后冒充最新观测。请把新数据单独保存，并按 `docs/输入与模型说明.md` 核对来源、区域和单位。
